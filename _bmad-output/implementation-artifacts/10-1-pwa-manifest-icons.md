# Story 10.1: PWA Manifest & Icons

Status: review

## Story

As a user,
I want the app to be installable on my device,
So that I can launch it like a native app without browser chrome.

## Acceptance Criteria

1. **Given** I visit the app on mobile or desktop
   **When** the browser detects the PWA manifest
   **Then** browser shows "Add to Home Screen" option

2. **Given** the manifest.json file
   **When** inspected
   **Then** it includes: name, short_name, icons (192x192, 512x512), start_url, display: standalone, theme_color, background_color

3. **Given** I install the PWA
   **When** I launch from home screen
   **Then** app opens in standalone mode without browser UI

## Dev Notes

### Technical Approach

Use `vite-plugin-pwa` which handles:
- Automatic manifest.webmanifest generation
- Service worker generation (via Workbox)
- Asset precaching
- Proper cache versioning

### vite.config.ts Integration

```typescript
import { VitePWA } from 'vite-plugin-pwa'

export default defineConfig({
  plugins: [
    react(),
    tailwindcss(),
    VitePWA({
      registerType: 'autoUpdate',
      manifest: {
        name: "Jon's Place IPTV",
        short_name: 'IPTV',
        description: 'Watch IPTV together',
        theme_color: '#0f172a', // slate-900
        background_color: '#0f172a',
        display: 'standalone',
        start_url: '/',
        icons: [
          { src: 'pwa-192x192.png', sizes: '192x192', type: 'image/png' },
          { src: 'pwa-512x512.png', sizes: '512x512', type: 'image/png' },
          { src: 'pwa-512x512.png', sizes: '512x512', type: 'image/png', purpose: 'maskable' }
        ]
      }
    })
  ],
  // ... rest of config
})
```

### Icon Requirements

| File | Size | Purpose |
|------|------|---------|
| pwa-192x192.png | 192x192 | Standard Android icon |
| pwa-512x512.png | 512x512 | Splash screen, large displays |
| apple-touch-icon.png | 180x180 | iOS home screen |

Icons should:
- Use simple, recognizable design (TV/play icon)
- Work on both light and dark backgrounds
- Have transparent or matching background for maskable

### Theme Colors

Match the existing app theme (slate-based):
- theme_color: `#0f172a` (slate-900)
- background_color: `#0f172a` (slate-900)

### index.html Additions

```html
<head>
  <!-- PWA Meta Tags -->
  <link rel="apple-touch-icon" href="/apple-touch-icon.png">
  <meta name="apple-mobile-web-app-capable" content="yes">
  <meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
  <meta name="theme-color" content="#0f172a">
</head>
```
