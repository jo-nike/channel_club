Status: review

## Story

As a user,
I want the app to have a distinctive favicon,
so that I can identify the tab easily in my browser.

3. **Given** I install the PWA **When** viewing the home screen icon **Then** the app icon matches the favicon design (existing PWA icons 192x192 and 512x512 already present)

### Favicon Generation Approach

**Option A: Use existing design tool**
- Figma, Canva, or similar to create base design
- Export at required sizes

**Option B: Use favicon generator service**
- realfavicongenerator.net - generates all required sizes from single image
- favicon.io - simple generator with text/emoji options

**Recommended design direction:**
- Simple, recognizable at 16x16
- TV/monitor icon, play button, or stylized "J" or "JP"
- Match the dark theme aesthetic (`#0f172a` background possible for PWA icons)
- High contrast for visibility

### PWA Manifest Configuration

The PWA manifest is generated by `vite-plugin-pwa`. Check `vite.config.ts` for icon configuration:

```ts
// Expected structure in vite.config.ts
VitePWA({
  manifest: {
    icons: [
      { src: '/pwa-192x192.png', sizes: '192x192', type: 'image/png' },
      { src: '/pwa-512x512.png', sizes: '512x512', type: 'image/png' },
      { src: '/pwa-512x512.png', sizes: '512x512', type: 'image/png', purpose: 'maskable' }
    ]
  }
})
```

### Icon Size Requirements

| File | Size | Purpose |
|------|------|---------|
| favicon.ico | 16x16, 32x32 | Browser tab (IE/legacy) |
| favicon-16x16.png | 16x16 | Browser tab (modern) |
| favicon-32x32.png | 32x32 | Browser tab (retina) |
| apple-touch-icon.png | 180x180 | iOS home screen |
| pwa-192x192.png | 192x192 | Android home screen |
| pwa-512x512.png | 512x512 | PWA splash screen |

### Project Structure Notes

- All favicon assets go in `frontend/public/`
- Files in public/ are served at root path (e.g., `/favicon.ico`)
- Do NOT place in `src/assets/` - those get bundled with hash names
